### 🟡 Неполная структура `Contact` (§15–16)

Текущая структура:
```rust
struct Contact { node_id, addr: SocketAddr, last_seen: u64 }
```
Требуемая по §16:
```rust
Contact { node_id, identity_algorithm, identity_public_key, host, port,
           last_seen_ms, last_verified_ms }
```
